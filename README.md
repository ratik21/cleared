# Paid

Paid gets Indian freelancers paid by foreign clients in USDT. A private AI writes the invoice from a voice note and chases clients who pay late.

This project is for ETHGlobal Mumbai (Nov 5–7, 2026). It enters three sponsor tracks: 0G Private Computer, EF Anon-RPC and Whitechain Payments Nobody Notices.

## Files

- `PLAN.md` is the full build plan: user flows, track requirements, architecture, data model, integrations, contract and relayer security, repo layout, schedule, demo script and risks.
- `docs/design-exploration/` holds the four design candidates the plan was built from, the shared brief they used (`GROUNDING.md`), and how the final design was chosen (`SYNTHESIS.md`).

The live, editable version of the plan is at https://claude.ai/artifact/2nnQ99AdkV5xufuSjvSQec.
